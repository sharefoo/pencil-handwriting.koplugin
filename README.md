# Pencil handwriting

KOReader 手写批注插件：在墨水屏阅读器上直接用数字笔在页面上书写，笔迹随内容保留、可擦除、按文档持久化。

> **版本**：0.9.9
> **适用设备**：带 Wacom/EMR 数字笔的墨水屏设备（Kindle Scribe / Scribe 3 / Colorsoft）
> **KOReader**：不限版本。新版走官方 stylus API，旧版自动回退到直读数字笔节点
> **仓库**：<https://github.com/sharefoo/pencil-handwriting.koplugin>

---

## 简介

针对 Kindle Scribe 系列的数字笔做了深度适配。输入层**优先复用 KOReader 官方的 stylus 回调**：它已经解析好笔的槽位与工具类型（笔 / 橡皮 / 高亮），并且可以**独占**笔事件，使笔画不会被误判成翻页手势。在较旧、不含该 API 的 KOReader 构建上，自动回退为直接读取数字笔的 evdev 节点（按 `BTN_TOOL_PEN` 能力自动定位节点），因此**不依赖 nightly 版本**也能工作。

书写采用**只加墨、不铺白**的方式：每段新笔迹直接画进实时 framebuffer，只刷新笔尖覆盖的矩形区域（fast/DU 局部刷新），页面正文不受影响；同时挂接 `ReaderView:paintTo`，KOReader 每次重绘（翻页、开菜单、旋转、擦除）之后都会把当前页笔画补画回去，所以笔记不会因重绘而丢失。

笔画按**文档页面坐标**存储（用 KOReader 自己的坐标变换测量），因此在 PDF 上改变缩放、滚动或旋转屏幕，笔迹都会跟着内容走，不会错位到别的内容上。

## 主要特性

- **手写笔迹录入**，笔宽 1–24 px、五档灰度可调
- **橡皮擦**（Premium Pen 笔尾或独立橡皮工具），划过即整笔删除
- **按文档持久化**：笔画保存在文档 sidecar 目录，重新打开自动恢复
- **缩放 / 滚动 / 旋转自适应**：分页文档（PDF 等）笔迹锚定在内容上
- **笔记常驻显示**，与「是否开启绘制」解耦：关掉绘制也能看到已写的笔记
- **可选「书写时屏蔽触摸」**，防止手掌误触翻页（顶部条带保留，菜单始终能点开）
- **可选「独占笔输入」**，供直读 evdev 路径下抑制笔触发的翻页
- **输入源可运行时切换**（自动 / KOReader stylus API / evdev 直读）
- **内置诊断面板**：输入源、节点列表、坐标空间、各类计数器与最近错误，绝大多数问题看这里就能定位
- **菜单跟随 KOReader 界面语言**：中文界面显示中文（插件名 `Pencil handwriting` 保持不变）

## 安装（速览）

1. 把 `pencil-handwriting.koplugin` **整个文件夹**复制到 Kindle 的 `koreader/plugins/` 下（文件夹内应直接看到 `_meta.lua` 与 `main.lua`）；
2. **完全退出** KOReader（不是退回主界面），再重新启动——插件只在启动时扫描一次；
3. 打开任意文档 → 顶部菜单 **第二栏（排版 / Typeset）** → 最下方 **Pencil handwriting** → 勾选 **Enable drawing（启用手写）**。

完整步骤、目录层级陷阱与验证方法见 **[安装操作文档.md](安装操作文档.md)**。

## 使用

### 菜单一览

进入 **主菜单 → 排版 → Pencil handwriting**：

| 菜单项 | 作用 |
|---|---|
| **Enable drawing**（启用手写） | 绘制总开关。按文档记忆，重开同一本书自动恢复 |
| **Width**（笔宽） | 预设 1 / 2 / 3 / 5 / 8 / 12 / 16 / 24（默认 3），或自定义 1–24 |
| **Color**（颜色） | Black / Gray 25% / Gray 50% / Gray 75% / White（默认 Black） |
| **Input source**（输入源） | 自动 / KOReader stylus API / evdev（直读），一般保持「自动」 |
| **Block touch while drawing**（书写时屏蔽触摸） | 默认关。手掌误触翻页时才开 |
| **Exclusive pen capture**（独占笔输入） | 默认关，仅 evdev 路径生效，开启有二次确认 |
| **Redraw strokes**（重绘笔迹） | 按已存数据强制重画，界面显示异常时用 |
| **Clear strokes on this page**（清除本页笔迹） | 清除本页，弹窗显示数量 |
| **Clear all strokes in document**（清除本文档所有笔迹） | 清除全文档，弹窗显示总数 |
| **Full refresh on page turn (test)**（翻页整屏刷新） | 测试用：每次翻页都整屏刷新 |
| **Input diagnostics**（输入诊断） | 诊断面板，排错必看 |

> 菜单文字跟随 KOReader 的界面语言；上表同时给出中文与英文原文，便于对照。

### 书写与擦除

| 操作 | 方式 |
|---|---|
| 写字 | 开启绘制后直接用笔在页面上写 |
| 擦除 | 用笔尾橡皮，或切换为橡皮工具后划过笔画 |
| 翻页 | 用**指尖**滑动 |
| 点菜单 | 用**指尖**——绘制开启时笔事件被插件接管，笔点不动菜单 |

> **橡皮擦是「划过即整笔删除」**，不是局部裁剪。因为插件只能加墨、不能涂白（涂白会盖住正文）。

### 绑定手势

插件向 KOReader 的 Dispatcher 注册了一个动作 **Pencil handwriting: toggle**，可在 **主菜单 → 工具 → 手势管理** 中绑到手势上（例如双指长按切换绘制），不必每次进菜单。

## 数据与备份

笔画数据保存在文档的 sidecar 目录中，文件名固定为：

```
<书名>.sdr/pencil_handwriting.lua
```

- **备份笔记** = 复制这个文件；换设备或重装后放回同一个 `.sdr` 目录即可恢复。
- 文件由插件自动读写，**不要在设备运行时手工编辑**。
- 删除 `.sdr` 目录会同时清掉笔记、阅读进度、书签等所有附属数据，请谨慎。

## 已知限制

- 不支持逐笔选中、改色、移动
- 橡皮擦为整笔删除，不能局部裁剪
- 无压感调宽（不读取压力值调制笔画粗细）
- **重排文档（EPUB / FB2）**：KOReader 不提供页面坐标系，笔画只能锚在屏幕坐标上，改动字号或版式后位置可能漂移。批注建议用 PDF
- 早期版本（存储格式 v1，屏幕坐标）写下的笔迹在加载时会被跳过，需要重画
- 绘制开启时笔无法操作菜单，需用指尖
- 墨迹极密的页面，翻页会变慢

## 常见问题

| 现象 | 先看这里 |
|---|---|
| 菜单里找不到 Pencil handwriting | 必须**打开文档后**在阅读界面看；插件只在启动时扫描，装完要**完全重启** KOReader |
| 插件加载失败并弹窗 | `pencilhw/` 子目录缺失或损坏，重新完整复制整个文件夹 |
| 开启了绘制但写不出笔画 | 把 **Input source** 切到「自动」，再打开 `Input diagnostics` 看节点与坐标 |
| 写字被识别成翻页 | 输入源保持「自动」；仍复现则开启 **Exclusive pen capture** |
| 笔迹翻页后消失 | 看诊断面板的 `Repaint hook` 是否为 `MISSING` |
| 笔迹出现在相邻页 | 看诊断面板的 `stroke space` 与 `Last stroke`（正常应为 `space=page`） |
| 橡皮擦没反应 | 看诊断面板的 `erase unmapped` 计数与 `Last slot` 的 `tool=` 值 |
| 菜单仍是英文 | 看诊断面板的 `language:` 一行；界面语言不是中文时菜单就保持英文 |

详细的判读方法与完整排错表见 **[安装操作文档.md](安装操作文档.md) 第八节**。

```
└── pencilhw/            插件私有命名空间（避免与其他插件的模块重名）
    ├── config.lua       版本号、设备路径提示、调色板、刷新与擦除参数
    ├── geometry.lua     面板原生坐标 ⇄ 当前屏幕坐标（旋转数学）
    ├── viewmap.lua      屏幕 ⇄ 文档页面坐标（向 KOReader 实测，逐页映射）
    ├── evdev.lua        直读数字笔节点的回退路径（设备发现、事件解析）
    ├── canvas.lua       无状态光栅器：把笔画画进指定的 Blitbuffer
    ├── store.lua        按页序列化笔画到 sidecar
    └── i18n.lua         菜单文本的语言词典
```

## 兼容性

- **输入路径**：KOReader nightly 2026.07.2-60 及以后提供 stylus 回调 API，插件优先使用；更早的构建自动走 evdev 直读。
- **文档类型**：分页文档（PDF / DjVu / CBZ）为最佳场景；重排文档（EPUB / FB2）可用，但位置会在版式变化后漂移。
- **其他品牌**：设备发现按「是否上报 `BTN_TOOL_PEN` / `BTN_TOOL_RUBBER`」的能力判断，理论上有 Wacom/EMR 数字笔的机型都可用；目前只在 Kindle Scribe 系列上实测过。

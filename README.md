### 简介
KOReader 的手写插件。针对 Kindle Scribe（含 Scribe 3 / Colorsoft）的数字笔做深度适配，输入层优先复用 KOReader 官方的 stylus 回调——它已解析好笔的槽位与工具类型，并且可以「独占」笔事件，使笔画不会被误判成翻页手势；在使用较旧、不含该 API 的 KOReader 构建时，自动回退为直接读取数字笔的 evdev 节点（按 BTN_TOOL_PEN 能力自动定位节点），因此不依赖 nightly 版本也能工作。

渲染采用「只加墨、不铺白」的方式：书写时每段新笔迹直接画进实时 framebuffer，只刷新笔尖覆盖的矩形区域（fast/DU 局部刷新），页面正文不受影响；同时挂接 ReaderView:paintTo，KOReader 每次重绘（翻页、开菜单、旋转、擦除）之后都会把当前页笔画补画回去，因此笔记不会因重绘而丢失。由于只能加墨，橡皮擦的语义是「划到哪里，哪条笔画消失」，而非涂白覆盖。

### 主要特性

- 手写笔迹录入，笔宽与灰度颜色可调
- 橡皮擦（Premium Pen 笔尾或独立橡皮工具）
- 笔画按页持久化到文档 sidecar 目录，重开后自动恢复
- 翻页、旋转自动适配；笔记常驻显示，与「是否开启绘制」解耦
- 可选「绘制时屏蔽触摸」，防止手掌误触翻页（顶部条带保留，菜单始终可点开）
- 可选「独占捕获笔节点」，供自读 evdev 路径下抑制笔触发的翻页
- 运行时可在菜单中切换输入源（自动 / KOReader stylus API / evdev 直读）
- 内置输入诊断面板：输入源、节点列表、计数器、原始轴范围与最后一次错误

### 已知限制
不支持逐笔选中/改色/移动；橡皮擦整笔删除而非局部裁剪；无压感调宽；流式文档（EPUB）重排后笔画位置可能漂移；绘制开启时笔不能操作菜单（请用指尖）；墨迹极密的页面翻页会变慢。
